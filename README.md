# ①課題名
ふくわらいビリヤード

## ②課題内容（どんな作品か）
- 福笑いとビリヤードを組み合わせた、2人対戦ゲームです。
- 顔の輪郭をビリヤードの台、顔のパーツ（まゆ・目・鼻・口）をボールに見立てて、パーツを弾いて正解の顔の配置に近づけます。
- 「シャッフルしてスタート」を押すと、パーツが飛び散って跳ね返り、止まった位置からゲームが始まります。
- パーツを押したまま後ろに引いて離すと打てます。引いた距離で強さ、引いた向きで飛ぶ方向が決まります。
- 本物のビリヤードと同じく、パーツは番号の順にしか打てません。2人で1打ずつ交代して、6打ずつ（合計12打）打ちます。
- 打ち終わったパーツは、1人2回まで、その場所に固定できます。固定したパーツはぶつかられても動きません。
- 12打終わったときに、正解の位置に近いほうが勝ちです。勝った側には「WIN!」と紙吹雪が出ます。

## ⑤工夫した点・こだわった点
- `Math.random()` でパーツを飛ばす速さと向きをランダムに決め、毎回違う配置から始まるようにした
- パーツ同士がぶつかると勢いが受け渡され、ぶつけられたパーツも飛んでいくようにした
- 顔の輪郭（楕円）の縁で跳ね返り、摩擦とぶつかるたびの減速で、最後には自然に止まるようにした
- 2人の台に同じシャッフル結果を使い、スタート時の条件が公平になるようにした
- 左右のまゆと目は、入れ替わっていても正解として点数を数えるようにした
- パーツを固定できる権利を1人2回分つけて、「どれを守るか」という駆け引きを入れた
- 「正解を見る」ボタンで正解の配置を確認でき、「もとに戻す」で続きから遊べるようにした
- マウスだけでなく、スマホの指でも打てるようにした

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 難しかった点：「福笑い × ビリヤード」というアイデアを、実際に遊べるルールに落とし込むこと。何打で終わるか、どう交代するか、何で勝ち負けを決めるかを一つずつ決める必要があった
- 難しかった点：遊んでみて初めて気づく問題が多かったこと。左右対称のまゆと目はどっちがどっちか分からなくなる、スタート時の配置がいつも同じだと単調になる、など。そのたびにルールを足して調整した
- 難しかった点：ゲームとして面白くするための要素を考えること。うまく置いたパーツが後の1打で弾かれてしまう悔しさをどうするか考えて、「固定できる権利」を足した
- 次回トライしたいこと：パーツの向き（回転）も得点に入れる
- 次回トライしたいこと：別々の端末から遊べるオンライン対戦
- 次回トライしたいこと：最高得点を記録して、ランキングを表示する
